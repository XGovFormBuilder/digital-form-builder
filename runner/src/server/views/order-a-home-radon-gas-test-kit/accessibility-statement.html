Accessibility statement for Radiation Protection Service

This accessibility statement applies to two online services:

  • Order a radon risk report (opens in new tab)
  • Order a home radon gas test kit

These services are run by the UK Health Security Agency (UKHSA). We want as many people as possible to be able to use them. For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or device settings
  • zoom in up to 400% without the text spilling off the screen
  • navigate most of the service using just a keyboard or speech recognition software
  • listen to most of the service using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver)

We've also made the text as simple as possible to understand. AbilityNet (opens in new tab) has advice on making your device easier to use if you have a disability.

How accessible these services are

We know some parts of these services are not fully accessible:

  • some form fields and groups of options are not properly labelled for screen readers
  • some fields do not support autofill, so you may need to type your details in full
  • some page titles and headings are not structured correctly
  • the navigation on the confirmation page may be inconsistent or lead to unavailable pages
  • the payment page, provided by a third-party supplier, has several issues including low colour contrast, unclear keyboard focus and unlabelled fields

Feedback and contact information

If you need information from these services in a different format, like accessible PDF, large print, easy read, audio recording or braille:

  • email: enquiries@radiation.ukhsa.gov.uk
  • call: 0113 267 9041, 8:30am to 4:30pm, Monday to Friday

We'll consider your request and get back to you in 5 working days.

Reporting accessibility problems with these services

We're always looking to improve the accessibility of these services. If you find any problems not listed on this page, or think we're not meeting accessibility requirements, contact enquiries@radiation.ukhsa.gov.uk.

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018 (the 'accessibility regulations'). If you're not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS) (opens in new tab).

Technical information about these services' accessibility

UKHSA is committed to making its websites accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

These services are partially compliant with the Web Content Accessibility Guidelines version 2.2 (opens in new tab) AA standard, due to the non-compliances listed below.

Non-accessible content

The content listed below is non-accessible for the following reasons.

Non-compliance with the accessibility regulations

Links

  • In the home radon gas test kit service, the 'Accessibility statement' and 'Help' links on every page lead to a 'Page not found' error. This fails WCAG 2.2 success criterion 2.4.4 (Link Purpose (In Context)).
  • In the home radon gas test kit service, 'Change' links on the check your answers page do not take you to the relevant part of the page you are changing. This fails WCAG 2.2 success criterion 2.4.4 (Link Purpose (In Context)).
  • Some link text does not make sense without the surrounding text. This fails WCAG 2.2 success criterion 2.4.4 (Link Purpose (In Context)).
  • The 'Privacy policy' and 'Terms and conditions' links open in a new tab without warning you. This fails WCAG 2.2 success criterion 2.4.4 (Link Purpose (In Context)).

Forms and labels

  • The 'First name' and 'Last name' fields do not have labels that screen readers can announce. This fails WCAG 2.2 success criterion 1.3.1 (Info and Relationships).
  • On the 'Select an address' and 'Is this address correct?' pages, the group of options does not have a heading (legend) that screen readers can announce. This fails WCAG 2.2 success criterion 1.3.1 (Info and Relationships).
  • One page contains a form field that is not used, which may confuse people. This fails WCAG 2.2 success criterion 3.3.2 (Labels or Instructions).

Autofill

  • Some fields, including email address and building number, are missing autocomplete settings or have incorrect ones. This means your browser may not be able to fill in your details for you. This fails WCAG 2.2 success criterion 1.3.5 (Identify Input Purpose).

Page titles, headings and structure

  • Screen readers read out the page title twice. This fails WCAG 2.2 success criterion 2.4.2 (Page Titled).
  • Some headings use the wrong heading level, which makes the page structure harder to follow. This fails WCAG 2.2 success criterion 2.4.6 (Headings and Labels).
  • Some pages use line breaks and empty code elements to create spacing, which some assistive technologies may announce. This fails WCAG 2.2 success criterion 1.3.1 (Info and Relationships).

Consistency

  • The confirmation page looks different from the rest of the service. This fails WCAG 2.2 success criterion 3.2.3 (Consistent Navigation).

Payment page provided by a third party

Both services use a payment page provided by our supplier, Trust Payments. We know this page has the following issues:

  • The page title does not describe the page. This fails WCAG 2.2 success criterion 2.4.2 (Page Titled).
  • It's hard to see which element has keyboard focus. This fails WCAG 2.2 success criterion 2.4.7 (Focus Visible).
  • The page language is not set correctly, so screen readers may not read it in the right language. This fails WCAG 2.2 success criterion 3.1.1 (Language of Page).
  • Some text and the status message banners do not have enough colour contrast. This fails WCAG 2.2 success criterion 1.4.3 (Contrast (Minimum)).
  • The expiry date month and year dropdowns, and some other form labels, are not linked to their fields, so screen readers cannot announce them. This fails WCAG 2.2 success criteria 1.3.1 (Info and Relationships) and 4.1.2 (Name, Role, Value).
  • The Trust Payments logo has no text alternative. This fails WCAG 2.2 success criterion 1.1.1 (Non-text Content).
  • Payment fields are missing autocomplete settings or have incorrect ones, so your browser may not be able to fill in your card details. This fails WCAG 2.2 success criterion 1.3.5 (Identify Input Purpose).

We're working with Trust Payments to fix these issues. If you cannot use the payment page, contact us using the details above and we'll help you complete your order.

What we're doing to improve accessibility

We plan to fix the issues in our own pages in our future release cycles. We're working with Trust Payments to fix the issues on the payment page. We'll update this statement as issues are fixed.

Preparation of this accessibility statement

This statement was prepared on 29 October 2026. It was last reviewed on 29 October 2026.

These services were last tested on 23 September 2026. The test was carried out by our internal UKHSA accessibility team. We tested all pages in both services, including the third-party payment page.

We reviewed the page code, used the WAVE automated accessibility tool, and tested the service manually using:

  • the JAWS, NVDA, Windows Narrator and VoiceOver screen readers
  • the Chrome, Firefox and Edge browsers
  • keyboard-only navigation
